Impact if unaddressed
CI gate failure; repository does not pass make lint or make check.

High

Proposed fix (not yet applied)

In crates/clio-lib/src/main.rs:103, replace `loop { let Some(flag) = pending.take().or_else(|| it.next()) else { break; }; ... }` with `while let Some(flag) = pending.take().or_else(|| it.next()) { ... }`.

02

Racy port allocation in `explicit_address_is_honored` causes intermittent test failure during coverage run

Important
Why it matters
The unit test binds to port 0, reads the assigned port, drops the listener, and immediately re-binds. If the socket lingers in TIME_WAIT or a parallel test thread binds the port, resolve_listener fails with AddrInUse (code 48).
Impact if unaddressed
Flaky test runs in CI and coverage gates (`make coverage` failed on the first run with 'bind explicit: Os { code: 48, kind: AddrInUse }').
Evidence
crates/clio-lib/src/http_bind_tests.rs:35:62 and crates/clio-lib/tests/mcp_http_bind_harness.rs:101-105
Confidence
High

Proposed fix (not yet applied)

Add a bounded retry loop when selecting and verifying an explicit port in http_bind_tests.rs and mcp_http_bind_harness.rs, similar to occupied_with_free_next().

Worth considering. Unlikely to change the substantive result.

03

CLI flag parser does not support `--bind=HOST:PORT` syntax and silently falls back to auto-bind

Minor
Why it matters
When a user passes `--bind=127.0.0.1:34305`, `parse_flags` does not split on `=` and stores key `bind=127.0.0.1:34305`. `flags.get("bind")` returns None, causing clio to silently auto-bind to 34300 instead of 34305.
Impact if unaddressed
Users passing standard `--flag=value` syntax receive no warning/error and are bound to an unexpected port.
Evidence
crates/clio-lib/src/main.rs:108: `target/debug/clio mcp http --bind=127.0.0.1:34305 --db sqlite::memory:` outputs 'mcp http listening on 127.0.0.1:34300'
Confidence
High

Proposed fix (not yet applied)

In parse_flags, check if flag contains `=` (e.g. `flag.split_once('=')`) or reject unrecognized flag tokens.
