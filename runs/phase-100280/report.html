02

Unsanitized HTTP response body snippets in error returns risk secret token leakage in AmError

Important
Why it matters
External HTTPS endpoints (OpenAI, Cohere, reverse proxies) often echo invalid client credentials in 401/403 error payloads. Embedding the raw body snippet in AmError violates NFR-6.
Impact if unaddressed
Exposed API keys may leak into telemetry, log files, or MCP tool errors.
Evidence
crates/clio-index/src/http.rs:211-215 formats body[..200] directly into the returned error message.
Confidence
High

Proposed fix (not yet applied)

Mask credentials in error body snippets or omit the response snippet on 401 and 403 status codes.

04

Unconditional '(sidecar unreachable)' on transport errors misclassifies terminal client errors as retryable

Minor
Why it matters
Errors such as ureq::Error::Tls (certificate verification failure) and BadUri are fatal client errors, not transient network drops.
Impact if unaddressed
Retrying permanent failures wastes client time and delays fail-closed error propagation.
Evidence
crates/clio-index/src/http.rs:120-125 unconditionally embeds '(sidecar unreachable): {reason}'.
Confidence
High

Proposed fix (not yet applied)

Exclude '(sidecar unreachable)' on ureq::Error::Tls, BadUri, and Protocol variants.

05

HttpEndpoint::parse fails on bare bracketed IPv6 literals due to naive colon splitting

Minor
Why it matters
Standard IPv6 addresses like [::1] contain multiple colons. Without an explicit port, rsplit_once(':') mistakenly interprets '1]' as the port number.
Impact if unaddressed
Localhost IPv6 endpoints like http://[::1]/embed fail to parse with 'invalid port 1]'.
Evidence
crates/clio-index/src/http.rs:68-77 splits authority with rsplit_once(':') without checking bracket boundaries.
Confidence
High

Proposed fix (not yet applied)

Handle IPv6 bracketed hosts before splitting on port colons.
